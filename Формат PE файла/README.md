# Лабораторная №1 — как запустить (пошагово)

## Что уже есть в папке

| Файл | Зачем |
|------|--------|
| `pe_parser.cpp` | **Исходный код** — его сдаёте преподавателю |
| `pe_parser.exe` | **Готовая программа** — её запускаете |
| `files\PE1.dll` | Тестовый файл №1 |
| `files\PE2.exe` | Тестовый файл №2 |
| `results\` | Примеры вывода (уже сохранены) |

**Вам ничего не нужно писать в код**, если только преподаватель не попросит доработать. Код уже готов.

---

## Как запустить (3 шага)

### Шаг 1. Откройте командную строку в папке проекта

1. Откройте проводник: `C:\Users\1\Desktop\Формат PE файла`
2. Кликните **в пустое место** в адресной строке проводника (где путь к папке)
3. Наберите `cmd` и нажмите **Enter**

Откроется чёрное окно — это командная строка. В начале строки должно быть что-то вроде:

```
C:\Users\1\Desktop\Формат PE файла>
```

### Шаг 2. Запустите анализ PE1.dll

Скопируйте и вставьте в окно (правой кнопкой → Вставить), нажмите **Enter**:

```
pe_parser.exe files\PE1.dll
```

Пойдёт **длинный** вывод (много экспортов) — это нормально.

### Шаг 3. Запустите анализ PE2.exe

```
pe_parser.exe files\PE2.exe
```

Вывод будет **короткий** (около 60 строк).

---

## Если пишет «pe_parser.exe не является внутренней командой»

Сначала соберите программу — в той же командной строке:

```
build.bat
```

Подождите, пока закончится. Потом снова:

```
pe_parser.exe files\PE1.dll
pe_parser.exe files\PE2.exe
```

---

## Сохранить результат в файл (для отчёта)

```
pe_parser.exe files\PE1.dll > results\PE1_output.txt
pe_parser.exe files\PE2.exe > results\PE2_output.txt
```

Потом откройте `results\PE1_output.txt` и `results\PE2_output.txt` блокнотом.

---

## Что сдавать преподавателю

1. **Файл `pe_parser.cpp`** — исходник на C++
2. **Скриншоты** запуска на `PE1.dll` и `PE2.exe` (или содержимое `results\`)
3. **Скриншоты кода** с комментариями (откройте `pe_parser.cpp` в Cursor/VS Code и сфотографируйте начало файла, разбор заголовков, импорт/экспорт)

---

## Что куда «писать» — кратко

| Вопрос | Ответ |
|--------|--------|
| Куда писать код? | Никуда — код уже в `pe_parser.cpp` |
| Что вводить в командной строке? | Только команды выше (`pe_parser.exe files\...`) |
| Куда писать путь к файлу? | После `pe_parser.exe` через пробел: `files\PE1.dll` |
| Нужно ли менять PE1/PE2? | Нет, они уже в папке `files\` |

---

## Альтернатива: запуск из Cursor

1. Меню **Terminal → New Terminal**
2. Убедитесь, что внизу путь к папке `Формат PE файла`
3. Введите:

```
.\pe_parser.exe .\files\PE2.exe
```

(для PowerShell; в обычном `cmd` — без точки: `pe_parser.exe files\PE2.exe`)
